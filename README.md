# KDiff

軽量・高速なファイル差分ビューア（Linux / Ubuntu 向け）。
**100 万行クラスのログファイル**でもフリーズせず比較できることを目標に、ゼロから作っています。

Tauri v2（Rust バックエンド）+ vanilla TypeScript + Vite。仮想スクロールを自前で制御するため、あえて JS フレームワークは使っていません。

設計の優先順位は **速度 > 軽量 > デザイン**。

## 特徴

- **大規模ファイル対応** — 100 万行 × 100 万行の差分が約 2.4 秒（release ビルド）。差分計算は Rust 側で行い、行データは全部フロントに渡さず、表示中の範囲だけを取得します。
- **仮想スクロール** — 固定行高でビューポート分だけ描画。WebKit の要素高さ上限（約 16.7M px）を超えないようスクロール領域をキャップしてマッピングし直しているため、最終行まで正しく表示されます。
- **左右独立の横スクロール** — 2 ペイン構成。横スクロールは左右別々、縦スクロールは同期。行番号は左端に固定。
- **インライン差分** — 変更行は文字レベルで差分を強調。
- **ナビゲーション** — 右端のミニマップ、変更箇所へのジャンプ（Alt+↑ / Alt+↓）、「全体 / 差分のみ」表示の切り替え（未変更行は `⋯ N 行を省略` に折りたたみ）。
- **ファイルの開き方** — 参照ボタン、または左右の枠へのドラッグ&ドロップ。
- **マルチウィンドウ** — `＋` ボタン / Ctrl+N で独立したウィンドウを追加。ウィンドウごとに別の比較を保持します。

## 動作環境

- Linux（Ubuntu など、WebKitGTK 4.1）
- [Rust](https://www.rust-lang.org/)（cargo 1.77 以上）
- [Node.js](https://nodejs.org/)（npm）

### システム依存パッケージ（Ubuntu）

Tauri のビルドに WebKitGTK などが必要です。初回のみ以下を実行してください。

```sh
sudo apt install -y libwebkit2gtk-4.1-dev build-essential curl wget file \
  libxdo-dev libssl-dev libayatana-appindicator3-dev librsvg2-dev pkg-config
```

## セットアップ

```sh
npm install
```

## 開発（アプリを起動）

```sh
npx tauri dev --release
```

> **Note**: 必ず `--release` を付けてください。debug ビルドは差分計算が 10〜50 倍遅く、大きいファイルでは固まったように見えます。

フロントエンドだけを確認したい場合は `npm run dev`（Vite 開発サーバ）。

## ビルド

```sh
npx tauri build
```

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `Alt` + `↓` | 次の変更へジャンプ |
| `Alt` + `↑` | 前の変更へジャンプ |
| `Ctrl` + `N` | 新しいウィンドウ |

## アーキテクチャ

- **Rust（`src-tauri/`）** — ファイル読み込み、行のハッシュ化、`similar` の Patience アルゴリズムによる行差分、整列済み行の保持。状態はウィンドウラベルをキーにウィンドウごとに保持し、`open_files` が統計と変更ブロックだけを、`get_rows(start, count)` が表示範囲の行だけを返します。
- **フロントエンド（`src/`）** — vanilla TS。仮想スクロール、インライン強調、ミニマップ、ペイン同期などの描画を担当。
